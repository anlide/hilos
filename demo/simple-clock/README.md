# Simple Clock Demo Project

**Complexity: 1/5**

Simplest demo: clock synchronized between all users.

## What is this?

Displays current time synchronized with server. All users see the same time in real-time. Updates every second through WebSocket.

### Features

- **Server-synchronized time**: All users see identical time in real-time
- **Minimal logic**: One agent sends time
- **Frontend**: Vue 3 + TypeScript shows clock

### Technical Highlights

- Basic WebSocket work
- Periodic updates
- Simplest architecture
