# Simple Rock-Paper-Scissors Demo Project

**Complexity: 1/5**

Simplest game demo: rock-paper-scissors for multiple players.

## What is this?

Multiple players play rock-paper-scissors simultaneously. Each player chooses their move (rock, paper, or scissors). After all players choose, results and winner are shown.

### Features

- **Multi-player game**: Several players play simultaneously
- **Simple logic**: One agent processes player moves
- **Game mechanics**: Winner determination, score counting, game statistics
- **Frontend**: Vue 3 + TypeScript with move selection, result display, score

### Technical Highlights

- Basic game logic
- Simultaneous action processing
- Real-time updates
- Simple scoring system without complex logic
