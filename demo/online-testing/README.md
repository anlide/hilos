# Online Testing Demo Project

**Complexity: 3/5**

Demo project demonstrating an online testing system with real-time updates.

## What is this?

System for conducting tests and exams online.

### Features

- **Test creation**: Teachers create tests with different question types (single choice, multiple choice, text answer)
- **Test configuration**: Time limits, number of attempts, grading system
- **Real-time testing**: Students take tests in real-time, results displayed immediately after completion
- **Statistics**: Answer statistics, correct answers, explanations
- **Real-time monitoring**: Teacher sees who is taking test, time remaining, each student's progress
- **AI analysis**: AI can analyze student answers and generate recommendations, automatic text answer checking
- **Frontend**: Vue 3 + TypeScript with test creation interface, test taking, results viewing, statistics

### Technical Highlights

- Form handling
- Timers
- Real-time state synchronization
- Grading system
- Statistics
- AI answer analysis
