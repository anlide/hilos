# Hilos Website Demo Project

**Complexity: 2/5**

Demo project demonstrating a static website with dynamic content.

## What is this?

Official Hilos Framework website with documentation, code examples, interactive demos, and blog.

### Features

- **Static site with dynamic content**: Static site, but content is pulled up-to-date as admin edits it
- **Real-time updates**: Admin edits content through admin panel, changes immediately appear on site through WebSocket updates without page reload
- **Frontend**: Vue 3 + TypeScript with SSR or static generation
- **SEO optimization**: Fast loading, responsive design

### Technical Highlights

- WebSocket integration with traditional static site
- Real-time content updates without reload
- Simple deployment of static site with dynamic capabilities
