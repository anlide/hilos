# E-commerce Shop Demo Project

**Complexity: 5/5**

Demo project demonstrating a full-featured e-commerce application with complete purchase cycle.

## What is this?

Full-featured shop: product catalog, shopping cart, order placement. Purchase of both physical goods and services (subscriptions, services).

### Features

- **Delivery emulation**: Real-time delivery tracking - after order placement, delivery simulation begins (order assembly, shipping, in transit, delivered)
- **Real-time price updates**: Price changes in admin panel immediately reflected on site for all users
- **Inventory management**: Product availability on warehouse updated in real-time, prevents overselling
- **Admin panel**: Manage products, prices, warehouse stock, discounts, promo codes, promotions in real-time
- **Service purchases**: Subscriptions, services, digital goods with automatic activation
- **Frontend**: Vue 3 + TypeScript with advanced product filtering, autocomplete search, product comparison, reviews, order tracking system, personal account

### Technical Highlights

- Payment processing
- Session management
- Concurrent order processing
- Real-time inventory
- External API integration (delivery, payments, analytics)
- Everything up-to-date at any moment through WebSocket
- Notification system, purchase history, product recommendations
