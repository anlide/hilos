# Simple Visitor Counter Demo Project

**Complexity: 1/5**

Maximally simplified demo for understanding the basics.

## What is this?

Simple counter showing the number of active visitors on the site. Updated in real-time through WebSocket.

### Features

- **Real-time updates**: When user enters page - counter increases, when leaves - decreases
- **Synchronized display**: All connected users see the current number simultaneously
- **Minimal logic**: One agent tracks connections
- **Frontend**: Vue 3 + TypeScript shows large counter, list of active users (optional)

### Technical Highlights

- Basic WebSocket work
- Simplest agent architecture
- Real-time updates without complex logic
- Perfect for first introduction to framework
