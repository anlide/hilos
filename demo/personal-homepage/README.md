# Personal Homepage Demo Project

**Complexity: 3/5**

Demo project demonstrating a multilingual website with AI capabilities.

## What is this?

Personal page with project portfolio, blog, contacts. Displays skills, technologies, work experience, education.

### Features

- **AI CV generation**: AI agent analyzes job description and generates personalized CV
- **Multilingual support**: Support for multiple languages (RU, EN, etc.) with switching without reload
- **Real-time updates**: WebSocket used for real-time content updates, live visit statistics, new post notifications
- **Frontend**: Vue 3 + TypeScript with language switching, responsive design, SEO optimization, dark/light theme

### Technical Highlights

- i18n implementation
- Content management
- AI integration for content generation
- Skills and portfolio system
