# Simple Event Calendar Demo Project

**Complexity: 2/5**

Simple event calendar with synchronization between users.

## What is this?

Create events with date, time, description. View events in calendar format (month, week, day). Changes by one user are visible to all others in real-time.

### Features

- **Event management**: Create events with date, time, description
- **Calendar view**: View events in calendar format (month, week, day)
- **Real-time sync**: Changes by one user visible to all others in real-time
- **Simple synchronization**: Event synchronization through WebSocket
- **Notifications**: Notifications about upcoming events
- **Frontend**: Vue 3 + TypeScript with calendar interface, event creation, viewing, editing

### Technical Highlights

- Work with dates and time
- Calendar interface
- Event synchronization
- Real-time updates
- Simple notification system
