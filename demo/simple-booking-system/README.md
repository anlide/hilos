# Simple Booking System Demo Project

**Complexity: 2/5**

Simple booking system for resources (rooms, equipment, etc.).

## What is this?

Create resources for booking (rooms, tables, equipment). Book resources for specific time. Check resource availability in real-time.

### Features

- **Resource management**: Create resources for booking
- **Booking system**: Book resources for specific time
- **Availability check**: Real-time resource availability checking
- **Conflict prevention**: Prevent double booking of same resource for same time
- **Real-time sync**: Changes by one user visible to all others in real-time
- **Frontend**: Vue 3 + TypeScript with booking calendar, resource creation, booking, availability viewing

### Technical Highlights

- Work with resources
- Availability checking
- Booking synchronization
- Real-time updates
- Conflict prevention for simultaneous bookings
