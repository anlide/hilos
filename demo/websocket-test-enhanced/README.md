# WebSocket Test Enhanced Demo Project

**Complexity: 3/5**

Extension to existing websocket-test demo with enhanced capabilities.

## What is this?

Base chat functionality remains, new capabilities are added.

### Features

- **AI moderation**: AI bot-moderator analyzes messages in real-time, automatically removes spam, insults, unwanted content
- **User management**: Can ban users, issue warnings
- **Conversational bots**: Bots supporting conversation answer frequent user questions
- **Donation integration**: Notifications about donations in chat
- **High-frequency processing**: Message processing, scaling to many users
- **Frontend**: Vue 3 + TypeScript with fast message scrolling, filtering, moderator panel

### Technical Highlights

- Extending existing demo with new capabilities
- AI moderation in real-time
- Payment system integration
