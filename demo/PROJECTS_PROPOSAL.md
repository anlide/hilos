# Предложения по Demo Проектам для Hilos Framework

## Описание существующего проекта

### websocket-test (Чат)
**Сложность: 3/5**

Демонстрация real-time чата с использованием WebSocket и расширенными возможностями.
Показывает базовую архитектуру агентов в worker процессах.

Базовая функциональность чата: real-time обмен сообщениями, боты поддерживающие беседу,
бот-модератор для управления чатом.

Расширенные возможности:
AI бот-модератор анализирует сообщения в реальном времени,
автоматически удаляет спам, оскорбления, нежелательный контент.
Может банить пользователей, выдавать предупреждения.

Боты поддерживающие беседу отвечают на частые вопросы пользователей.
Интеграция с донатами - уведомления о донатах в чате.

Обработка высокочастотных сообщений, масштабирование на множество пользователей.
Frontend на Vue 3 + TypeScript (часть framework) с автоматическим переподключением,
быстрой прокруткой сообщений, фильтрацией, модераторской панелью.

Идеально для понимания основ работы с WebSocket и агентами в Hilos,
AI модерации в реальном времени, интеграции с платежными системами.

### 1. traivan-map-analyzer
**Чтение и анализ map.sql из игры Traivan**  
**Сложность: 4/5**

Демонстрация многопоточной обработки больших SQL дампов.
Проект читает map.sql файлы игры Traivan из разных доменов в параллельных потоках.

Один поток сканирует и ищет новые домены для чтения map.sql файлов.
Несколько потоков параллельно читают и парсят структуру карт (локации, объекты, связи).
Отдельные потоки обрабатывают события и строят графы карт.
AI агент генерирует аналитические отчёты на основе собранных данных.

Frontend на Vue 3 + TypeScript визуализирует карты как интерактивные графы.
Возможность поиска путей между локациями, фильтрации по типам объектов,
отображения статистики, зум и панорамирование.

Показывает работу с файловой системой, парсингом SQL в многопоточном режиме,
алгоритмы графов, кэширование больших структур данных в памяти.
Real-time визуализация через WebSocket.
AI анализ и генерация отчётов о структуре карт.

### 2. binance-btc-tracker
**Трекинг цен Bitcoin с Binance и вычисления на лету**  
**Сложность: 4/5**

Демонстрация работы с внешними API и real-time вычислениями в многопоточном режиме.

Несколько потоков параллельно подключаются к WebSocket API Binance.
Каждый поток читает данные по разным торговым парам или таймфреймам.
Отдельные потоки обрабатывают индикаторы (SMA, EMA, RSI, MACD, Bollinger Bands)
в реальном времени, определяют паттерны (поддержка/сопротивление, тренды).

Специальный поток обрабатывает данные и отправляет уведомления в Telegram бота.
Telegram бот предоставляет интерфейс для настройки алертов,
получения сигналов и статистики.

Frontend на Vue 3 + TypeScript показывает интерактивный график цен с индикаторами,
настраиваемые алерты, историю сигналов, статистику волатильности, объемы торгов.

Показывает работу с внешними WebSocket API, обработку потоков данных,
математические вычисления в реальном времени, интеграцию с Telegram Bot API.
Кэширование исторических данных для быстрого доступа.
Демонстрирует производительность при обработке высокочастотных обновлений.

Настройка расписания рейдов, управление ролями игроков,

Frontend на Vue 3 + TypeScript с отображением текущего рейда,
