# Routed Rule

A catalog file a wrapper points at. It says nothing about routing, and it does
not have to: the route lives in the wrapper.

A file explaining the mechanism has to show the refusal line, and showing is not
declaring:

```text
Routed from: none — an example inside a fence, which must not count
```

This file is routed, so were the line above taken at face value it would be
reported as routed and declining at once.

## Core Rule

This heading exists so the anchored link in the toy wrapper has a section to
name.
