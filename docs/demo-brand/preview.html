Phone home-screen tiles

The markup imitates <name>-touch-180.png, which export.cjs writes: the -large file at 140 px on an opaque #FFFFFF square of 180 × 180 CSS px, 20 px of padding on every side. The PNG itself is an export and is not kept in the repository. The rounded corners only illustrate the mask that iOS lays over the square tile; the file has square corners, and the platform rounds them.

What to review

At each size, check that the bolt reads as a bolt and not as a smudge. The variant is chosen by the CSS size of the circle; a high-density screen does not change it. Below 10 px the logo is the circle alone.

One file and one shade serve both backgrounds. The bolt sits only on the circle; the circle is what meets the background.

For each demo sign, check that the symbol reads on both backgrounds from one file, that the gap keeps it apart from the mark, and that the mark at 16 px is a dot and from 32 the bolt with two bends.

For each phone tile, check that the symbol and the mark stay clear of the rounded corners. The real browser tab and home-screen icon are checked on the devices: a headless browser draws neither.

This sheet loads only local SVG files. It needs no server, JavaScript, web fonts or network.
